The Analogy: Think of a Class as the plastic mold for making Gujiya (or a blank form at a bank). It doesn't have the filling yet; it just dictates the shape. An Object (or Instance) is the actual physical Gujiya you made using that mold, filled with your specific choice of dry fruits.

When you fill out the bank form with your specific details (Name, ID, Deposit Amount), that filled-out form becomes an Object (an Instance). You can use that single blank form (Class) to create infinite specific customer forms (Objects).

Creating a Class and an Object
Classes in Python are defined using the ```class``` keyword. By convention, Class names should always be capitalized.
```
class Car:
    # The __init__ method is the "Constructor". 
    # It runs automatically the exact moment an object is created.
    def __init__(self, user_brand, user_model):
        
        # 'self' establishes the internal connection line (context)
        # It means "MY brand is whatever the user passed in"
        self.brand = user_brand
        self.model = user_model

# Creating an Object (Instance) from the Class
my_car = Car("Toyota", "Safari")

# Accessing the Object's attributes (variables)
print(my_car.brand) # Outputs: Toyota
```
