Problem Statement: Create a function that takes two numbers as parameters and returns their sum.

In the second problem, we use the foundation of the first one. 
Now that we know how to define a function and properly return a value, the goal is to scale that function to handle multiple pieces of data simultaneously.

The Core Concept: Comma-Separated Parameters
Functions are not limited to a single input. You can pass as many pieces of data into a function as you need by separating the parameters with a comma. 
We emphasizes that while you could name your parameters anything (like ```a``` and ```b```), it is always better to use descriptive, readable names so that other developers know exactly what the function expects.
```
def add(num1, num2):
    return num1 + num2

print(add(5, 5))

# Console Output: 10
```
